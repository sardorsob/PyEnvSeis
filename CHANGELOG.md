# Changelog

## 0.1.0a2

- Reproduce the scoped eseis 0.8.1 default periodogram, spectrogram and
  fluvial-workflow interpolation in Python.
- Compute turbulence and bedload powers and build an ordered fluvial catalogue.
- Match aligned dB spectra using the eseis scoring rule and report score
  margins and absolute per-frequency residuals.
- Update project URLs to PyEnvSeis.

## 0.1.0a1

- Estimate one-sided velocity power spectra and windowed PSDs.
- Preserve waveform gaps and interpolate within the observed frequency band.
- Match observed PSDs to a caller-supplied catalogue and report fit errors in dB.
